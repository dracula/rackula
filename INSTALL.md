### [Rackula](https://count.racku.la)

Rackula is a drag-and-drop rack layout visualizer, meant to help you plan and document your server or AV racks. 

Rackula uses the Dracula color palettes, both clasic Dracula and Alucard, natively so no separate theme installation is required.

#### Activating theme

1. Visit [count.racku.la](https://count.racku.la) or download the container or source code from [GitHub Releases](https://github.com/RackulaLives/Rackula/releases)
2. Install the application
3. Dracula theme is used by default  🧛🏻‍♂️✨
